Self-serve printer setup

Connect to the PaperCut printers at your site

Pick your location below, then follow the steps for your laptop. Takes about 5–10 minutes, one time only.

1. Select your site

Install the printer

Selected site: — steps below update automatically for that server address.

Shared login for first-time setup: Username pcmf / Password pcmf. This unlocks the shared PCClient folder only — once installed, PaperCut will ask for your own network username and password to actually release print jobs.
  1. Open the shared PCClient folder

    Press Win + R to open the Run box, type the address below, and press Enter.

    \\10.10.0.9\
  2. Sign in with the shared credentials

    A Windows Security popup asks for network credentials. Enter these, tick Remember my credentials, then click OK.

    Username: pcmfPassword: pcmf
  3. Open the PCClient installer

    In the folder that opens, double-click PCClient → win, then run client-local-install.

    Windows will show a "We can't verify who created this file" warning — this is expected for an internal server. Click Run.

  4. Step through the PaperCut MF Client setup

    Accept the license agreement → Next. Leave the component set as Local Install (For all users) → Next → Install. If prompted, let the installer automatically close the running pc-client app to continue.

  5. Finish and verify your identity

    On the final screen, keep Launch client and verify my identity checked and click Finish.

  6. Log in with your own credentials

    A PaperCut login popup appears asking for printer access. Enter your own network username and password (not the shared pcmf login), tick Remember my identity, and click OK.

  7. Install the printer for your location

    Back in the shared folder, find the printer icon matching your floor/location (e.g. HC4_Printer_01) and double-click it to install the print queue on your laptop.

  8. Print a test page

    The first time you print, a popup will ask for your credentials again — check Remember my credentials so you won't be asked every time.

Alternative for UBZ: Mobility Print installer
This site also offers a simpler wizard-based installer — you can use this instead of the PCClient steps above.
  1. Open the Mobility Print setup page

    Go to the address below in your browser and download the printer setup file.

    http://10.30.0.9:9163/client-setup/known-host/windows.html
  2. Run the downloaded installer

    Open the downloaded setup file to start the wizard.

  3. Choose the setup language

    Select English, then click OK to continue.

  4. Accept the license agreement

    Review the agreement, select I accept the agreement, then click Next.

  5. Let it retrieve the printer list

    The installer connects to the server and pulls the list of available printers.

  6. Select your printer

    Pick the correct printer from the list and click Next.

  7. Enter the shared credentials

    Enter the shared login below and click Next.

    User: pcmfPassword: pcmf
  8. Finish

    Click Finish to complete the install — the printer is ready to use.

  1. Connect to the shared server

    In Finder, click Go → Connect to Server (or press ⌘K). Enter the address below and click Connect.

    smb://10.10.0.9/PCClient
  2. Sign in with the shared credentials

    Choose Registered User, enter the login below, tick Remember this password in my keychain, and click Connect.

    Name: pcmfPassword: pcmf
  3. Install the PCClient app

    Open the mac folder and run client-local-install. Click Yes when asked to install PCClient into the Applications folder.

  4. Log in with your own credentials

    A login popup appears asking for printer access. Enter your own network username and password (not the shared pcmf login), tick Remember my identity, and click OK.

  5. Open the printer setup page in your browser

    Go to the address below, click Download to get the Mobility Print client, then open the downloaded .pkg file.

    http://10.10.0.9:9163/client-setup/macos.html
  6. Run the Mobility Print installer

    Click through Continue → Agree to the license, then Install. Enter your Mac's admin password when prompted, then click Install Software.

  7. Confirm installation and print a test page

    You'll see "The installation was successful" — click Close. Your site's printers will now appear normally in any app's Print dialog.

Common issues

Try the matching fix before contacting the front desk.

Double-check you typed pcmf / pcmf exactly (lowercase, no spaces) — this is the shared login for the install step only, separate from your personal network login used later in PaperCut.

Confirm you're on the office/workspace network, not a personal hotspot or guest Wi-Fi — these server addresses are only reachable from the internal network at each site.

This warning is expected because the installer runs from a network path rather than a local download. As long as the address matches your site's server, click Run to continue.

Reopen the client-setup page for your site and re-run the installer — Mobility Print sometimes needs the browser step repeated once after the PCClient install finishes.

Either works. The PCClient steps match every other site, so use those if you want one consistent process. The Mobility Print installer (shown below the main steps when UBZ, BLR or DDN is selected) is a shorter wizard if you'd rather skip the shared-folder step entirely.

Make sure you ticked "Remember my identity" / "Remember my credentials" at the login popup. If it keeps resetting, your account password may have changed recently — re-enter it once and tick remember again.

Still stuck?

Message the front desk with your site name, OS, and the exact error text — that's usually enough to fix it without a call.
